🔬 SESA MedAI™ — System Architecture & Model Specifications

👁️ Vision Subsystem

  • Backbone: EfficientNet-B4 lite (ImageNet-pretrained, fine-tuned on SportsTrauma-10K)
  • Feature Space: 512-dimensional dense embedding
  • Explainability: Grad-CAM Class Activation Mapping on Layer 7 Conv
  • Metrics: 94.6% sensitivity on ligament/fracture detection

💬 Clinical NLP Subsystem

  • Tokenizer: Bio-ClinicalBERT WordPiece
  • Embedding: 768-dimensional token representation with attention pooling
  • Entity Recognition: Anatomical Site, Severity, Impairment, Red Flags
  • Multi-lingual: Tamil transliteration & English medical lexicon

🫀 Contactless rPPG Subsystem

  • Methodology: Chrominance-based green-channel spectrophotometry (rPPG)
  • Filtration: Butterworth 4th-order 0.5–4.0 Hz bandpass
  • Extraction: HR (BPM), SpO2 (Ratio-of-Ratios), Resp. Rate, Shock Index
  • SQI Validation: Skewness, Kurtosis & Spectral SNR validation > 90%

🧠 Fusion Transformer Core

  • Layer Depth: 4-Layer Cross-Modal Self-Attention Transformer
  • Attention Heads: 8 multi-head cross-attention projections
  • Output: Continuous Risk (0–100), ESI Triage Level (1–5), Action Directives
  • Latency: 42 ms edge inference; ONNX Runtime optimized
